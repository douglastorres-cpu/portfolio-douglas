Analytics Pro API v2.4
REST JSON Base URL: https://api.analyticspro.app/v2
Introducción
La API de Analytics Pro permite integrar métricas, transacciones e inventario en tus aplicaciones. Utiliza autenticación mediante JWT Bearer tokens con expiración de 24 horas.
Autenticación
POST /auth/login Content-Type: application/json { "email": "tu@email.com", "password": "••••••••" } → { "token": "eyJhbGci...", "expires_in": 86400 }
Incluye el token en todas las peticiones como header Authorization: Bearer <token>
Endpoints principales
GET/dashboard/summaryResumen general
GET/usersListar usuarios
POST/usersCrear usuario
GET/transactionsListar transacciones
POST/transactionsNueva transacción
GET/inventoryListar productos
DEL/inventory/:idEliminar producto
Códigos de respuesta
La API utiliza códigos HTTP estándar: 200 OK, 201 Creado, 400 Error de validación, 401 No autenticado, 403 Sin permisos, 404 No encontrado, 429 Rate limit (100 req/min), 500 Error interno.
// Ejemplo de error { "error": "VALIDATION_FAILED", "message": "El campo 'email' es requerido", "code": 400 }
Rate Limiting
Máximo 100 peticiones por minuto por token. El header X-RateLimit-Remaining indica cuántas quedan.
